# 直線勾配の実績分離

## 完了範囲

- `finish-topography-shadow.mjs` で直線の平坦/上りと道中の起伏を別項目にした。
- 確認済みJRA芝9場を対象とし、函館・ダート・海外・新潟直線1000mは推測せず対象外とする。
- 同じ馬の過去走だけを使用。同じ芝・今回距離±200m、基準日より前の着順を集計する。
- 未来・同日・日付不明・重複・異常結果を除外。未取得の着差は0にしない。
- 同会場・同距離の直接実績を別に表示する。
- 距離が完全一致し、G1/G2/G3等の格区分と良/湿馬場区分が重なる実績を別集計する。
- 両群3走以上の重複条件データがなければ比較データ不足とする。あっても記述比較であり、坂の因果効果とは扱わない。
- スワンS登録21頭のレポートを生成。既存指数・公開データ・係数・自動更新ランナーは変更しない。

## オフトレイル

2026-10-07基準、芝1200〜1600mの取得済み実績では、直線平坦9走/3着以内7回、上り坂7走/3着以内1回。
京都芝1400mは3走/3着以内3回。直接実績として残す。
同距離・格・馬場が重なる比較は平坦2走、上り坂4走。判断保留。
平坦群には下級条件時代の実績もあるため、単純な率の差で平坦巧者と断定しない。

## 残る交絡と運用

相手の能力、世代限定戦/混合戦、斤量、展開、直線の長さ、内外回り、成長、休養、開催時の馬場は統制していない。
世代分離は今回の直線勾配検証とは別課題。条件重複の集計だけで完全補正したと表現しない。
データ量の閾値は安全上の保留条件であり、検証済みの予測最適値ではない。
本番AI/UIには未接続。シャドー出力の `indexAdjustment` は常に0。
現在の形態辞書は現代のJRAコース対象で、古い改修前データの分析には使用しない。

## 再実行

```powershell
node --test tools/intelligence/tests/finish-topography-shadow.test.mjs
```
