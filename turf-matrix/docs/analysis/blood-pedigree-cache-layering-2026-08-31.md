# 4代血統キャッシュ階層化 (2026-08-31)

## 原因

- レース別の4代血統HTMLが1件でも存在すると、同じレースの残り全馬についてJV-Link血統へのフォールバックが無効になる全体切替だった。
- 過去に取得済みの共通4代血統HTMLは、現行のレースバッチ生成で再利用されていなかった。

## 修正

馬ごとに次の順で血統を選択する。

1. レース別4代血統HTML
2. 取得済み4代血統HTMLキャッシュ
3. JV-Link RCVN/UMの3代相当14祖先
4. basic.txt

4代HTMLを採用する際は、JV-Linkの父・母・母父と比較可能な項目が2件以上一致することを条件とする。馬名だけの一致ではキャッシュを採用しない。レース別HTMLがJV-Linkと矛盾する場合もJV-Linkへ戻す。
