# 斤量評価 採否決定 2026-07-27

## 決定

斤量補正はTM INDEXへ導入しない。斤量評価は採用見送りとし、斤量は引き続き表示情報としてのみ扱う。

後から係数や閾値を調整して斤量補正を復活させない。再検討には、今回とは異なる識別戦略と事前に定めた受入基準を必要とする。

## 根拠

1. 同一馬内の斤量増減と着順変化は無相関だった（Spearman 0.028）。
2. 斤量帯別に単調傾向はなく、`-3kg以上減`の複勝率22.6%が全帯で最低となり、期待方向と逆だった。
3. 「斤量減」には前走不振や降級という交絡が強く、斤量減の恩恵が、減量に至った原因のマイナスに打ち消されていると判断する。
4. ハンデ・別定・馬齢・定量の条件別でも、着順変化との相関はすべて絶対値0.15未満で、実用的な効果を検出できなかった。
5. 今回観測した問題は単純なサンプル不足ではなく構造的交絡であり、同じ設計のままデータ件数だけを増やしても解消しないと判断する。

詳細な集計値は `docs/analysis/weight-effect-2026-07-26.md` を参照する。

## 今後の方針

- 斤量補正はTM INDEXへ導入しない。
- 斤量は表示のみとし、Ability・Course・Paceなどのスコアリング入力へ追加しない。
- 次の精度改善候補は「相手関係／レースレベル評価」とする。
- 相手関係は斤量よりも馬の不振との交絡が少ないと見込むが、直ちに補正へ採用しない。
- 相手関係補正の検証は、100〜300頭かつ複数週の結果アーカイブ蓄積後に開始する。

## 今週の運用

- 現行TM INDEXのまま通常公開する。
- `engine-stats`による計測を継続する。
- 公開時スナップショットと確定結果のarchive蓄積を継続する。
- 本決定に伴う本番コード、重み、UI、`week-data.json`の変更は行わない。
