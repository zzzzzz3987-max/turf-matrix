# Blood個別プロフィール統合レポート（2026-08-29）

## 目的

- 父・母父の個別辞書に名前がない場合も、取得済みの父母から説明可能にする。
- 個別プロフィールの特徴を、今回条件との適合としてBloodスコアへ限定的に反映する。
- 辞書照合数やcoverageそのものを加点理由にしない。

## 算出方法

1. 個別プロフィールの特徴語を speed / power / stamina / sustain の固定ベクトルへ変換する。
2. 今回の距離・芝ダート・馬場・主要コースタグとの適合度を算出する。
3. 同じレース条件に対する辞書全プロフィールの適合度中央値を中立点とする。
4. 父0.40・母父0.25を照合できたプロフィール間で再正規化して統合する。
5. 個別プロフィール補正は最大±1.5点とする。既存の系統評価と統計補正は変更しない。

出走馬、着順、人気、オッズはプロフィールベクトルおよび係数の決定に使用していない。
