# 注目穴 Frame Evidence what-if

## 固定ルール

- 対象はTM INDEX 3〜5位かつValue適格、人気より指数順位が2段以上高い馬。
- Ability・Form・Training・Pace・Distance・Courseと、過去の展開不利Evidenceで作るPace v3を基準とする。
- Frame v2の補正は最大±1点。Confidence A〜Cは全量、Dは半量、Lowは不使用。
- 各開催日の枠モデルは、その日より前の確定結果だけで再構築する。
- 結果を見た後の係数変更は行わない。

## 結果

対象は発走前に固定済みの11日・105レース。Pace v3とFrame追加版の両方で注目穴が存在した51レースを比較した。

| 方式 | 変更 | 1着 | 3着内 | 複勝回収率 |
|---|---:|---:|---:|---:|
| Pace v3 | - | 3.9% | 21.6% | 80.4% |
| Pace + Frame | 3件 | 3.9% | 19.6% | 58.0% |

## 判定

Frame Evidenceの注目穴接続は不採用。枠順AIは独立した影評価として前向き検証を続ける。注目穴は、現時点で最も成績が良いPace v3を発走前固定し、採用ゲートを評価する。

Pace v3は同一51レースの現行公開方式と比べ、3着内率15.7%から21.6%、複勝回収率55.1%から80.4%へ改善した。ただしこれは回顧what-ifであり、本番公開への接続は前向き30件以上・選択変更5件以上・3着内率改善・複勝回収率維持を満たしてから行う。
