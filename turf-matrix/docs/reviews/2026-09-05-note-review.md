# 【9月5日・土曜回顧】札幌2歳Sは選出3頭で1〜3着決着。それでも指数1位は0勝

9月5日（土）にTURF MATRIXで公開した、札幌・阪神・中山の特別9レースを振り返ります。

集計は発走前に公開した予測を固定し、JV-Linkから取得した確定結果・払戻と照合しています。回収率は、対象馬を1頭につき100円購入した場合の数値です。

勝負レースの札幌2歳ステークスは、選出した3頭で1〜3着まで決着しました。一方、土曜全体では指数1位が0勝。3頭を選ぶ精度と、その中から本命・買い目を決める精度の差が表れた一日です。

## まずは結論

TM INDEX上位3頭は27頭中3勝、14頭が3着以内でした。複勝の払戻対象は13頭です。

・単勝回収率：55.9%

・複勝回収率：105.9%

複勝では損益分岐を上回りましたが、指数1位は9頭すべて敗戦。上位候補を残す力は見せた一方、その中から勝ち馬を1位へ置く精度には明確な課題が残りました。

順位別に見ると、内容の差がさらにはっきりします。

・指数1位：0勝、3着内5頭、単勝0%、複勝77.8%

・指数2位：1勝、3着内7頭、単勝77.8%、複勝201.1%

・指数3位：2勝、3着内2頭、単勝90.0%、複勝38.9%

今週も指数2位が非常に強く、9頭中7頭が馬券圏内。指数1位だけを切り取れば完敗ですが、能力上位の並び全体が崩れていたわけではありません。

## 札幌2歳Sは上位3頭で1〜3着

勝負レースに選んだ札幌2歳ステークスは、公開した3頭がそのまま1〜3着に入りました。

1着　指数3位・相手2　ショウナンガレオン

2着　指数2位・相手1　コスモハナミズキ

3着　指数1位・軸　デザートスピリット

能力評価としては、出走9頭の上位3頭を正しく絞り込めています。一方、公開買い目は「単勝3、馬連3-4、ワイド3-2」。的中はワイド3-2の250円だけで、3点300円に対する回収率は83.3%でした。

ここは、予測より買い方に課題がありました。

発走前の評価では、コスモハナミズキはTM INDEX 77、期待値1.85。デザートスピリットとのワイドは4.7〜6.5倍でした。対してショウナンガレオンは期待値0.13で、ワイドは2.4〜3.1倍。軸との安定した組み合わせとして見るなら、相手1のコスモハナミズキを選ぶ余地が十分にありました。

実際のワイド3-4は470円。ただし、これは結果を見た後の的中扱いにはしません。公開成績はあくまでワイド3-2の250円として記録します。

そのうえで、次回からはワイドを「相手2固定」にせず、相手1と相手2のTM INDEX、期待値、分析の信頼度、ワイド下限オッズを発走前に比較して選ぶ方式へ変更しました。同じ発走前データで今回を再判定すると、ワイド3-4を選ぶルールです。

指数1位は0勝でしたが、5頭は3着以内に残りました。1番人気2頭を含む一方、10倍以上の本命も4頭おり、単に低オッズ馬へ寄せた結果ではありません。

西宮ステークスは7頭立てだったため、3着サウンドムーブは複勝の払戻対象外です。このため、着順上は5頭が3着以内、馬券集計上の複勝的中は4件となります。

最も痛かったのは、指数1位の能力評価が完全に外れたというより、2位・3位との僅差を勝ち切り順位へ正しく変換できなかったことです。

西宮ステークスでは指数2位コルレオニスが1着、エニフステークスでは指数3位ゴッドブルービーが1着。札幌2歳Sも指数3位ショウナンガレオンが勝ちました。勝ち馬3頭はすべて指数上位3頭の中にいましたが、1位には置けませんでした。

今後は総合点だけでなく、当日の馬場傾向、位置取り、前傾・後傾ペースへの適性、展開に逆らった過去走を使い、「能力上位の中で今日もっとも勝ち切りやすい馬」を分けて検証します。

## 注目穴はピコローズが10番人気1着

公開した「注目穴」は8頭。1頭が勝利し、2頭が3着以内でした。

・単勝回収率：245.0%

・複勝回収率：113.8%

京成杯オータムハンデでは、注目穴ピコローズが10番人気で1着。単勝1,960円、複勝480円でした。

単純にオッズが高い馬を拾ったのではなく、TM INDEXと市場人気のズレに、近走内容や展開適性の裏付けがある馬を選ぶ現在の方向性が結果につながりました。ただし、8頭中6頭は馬券圏外です。1日の高配当だけで完成とは判断せず、同じ基準を固定して蓄積を続けます。

一方、「危険な人気馬」は公開4頭がすべて3着外。今回は人気馬を疑う材料として機能しました。こちらも的中率だけでなく、対象馬の人気帯やレース条件を分けながら精度を確認します。

## 期待値表示はプラスでも、候補の絞り込みが必要

画面上の期待値上位として集計した21頭は、2勝、6頭が3着以内でした。

・単勝回収率：126.7%

・複勝回収率：107.6%

単複ともに100%を超えましたが、期待値の生値だけで選んだ各レース上位3頭は、単勝25.9%、複勝35.9%でした。

この差は重要です。高いオッズだけで期待値が膨らんだ馬を並べるのではなく、能力・近走・調教・展開の裏付けで候補を絞る必要があります。ピコローズのような馬を拾いつつ、根拠の薄い大穴を増やさないことが次の課題です。

## 今週の評価

良かった点は、指数上位3頭の複勝回収率が105.9%となり、札幌2歳Sでは1〜3着をすべて捕捉できたこと。注目穴ピコローズの10番人気1着、危険な人気馬4頭の全頭馬券外も、役割別分析の前進でした。

悪かった点は明確です。指数1位は0勝。勝負レースも3頭の評価は合っていたのに、買い目へ正しく落とし込めず回収率83.3%に終わりました。

「上位3頭に入れられた」ことと、「本命を当てた」ことと、「買い目で利益を出した」ことは別です。今回はその違いがはっきり出た一日でした。

TURF MATRIXでは、公開後に都合よく成績を書き換えず、事前予測と実際の払戻を同じ条件で記録します。良かった部分は残し、外した理由は能力順位・展開・市場評価・券種選択に分けて改善していきます。
