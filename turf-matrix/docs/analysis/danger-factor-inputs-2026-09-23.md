# 危険判定した勝ち馬の能力・近走・調教点検

## 範囲と再現性

9/19〜9/22の発走前掲載スナップショットをSHA-256で照合し、特別レース18戦・全240頭を検査。勝ち馬4頭だけでなく同じ入力規則を全頭に適用した。

調教の旧日付区分による再計算は、指数に使わない欠損値をnullに戻す既存契約を適用すると、保存済み点数と240/240頭で一致した。比較の両方式は現在の厩舎・調教履歴辞書を共通利用しており、旧版全体を完全復元したものではない。

## 調教の日付区分を修正

従来は全曜日共通でレース1〜4日前を最終、5〜12日前を一週前としていた。月曜開催では水曜追いが5日前、火曜開催では6日前になるため、一週前へ分類されていた。

新しい `weekend-aligned-v2` では土日の境界を維持し、月曜は最終5日前・一週前13日前まで、火曜は最終6日前・一週前14日前まで拡張する。それぞれの区分内で代表時計を選ぶ既存ロジックと重みは維持。過去好走時の比較にも、その過去レースの曜日に対応した同じ規則を使う。

「最終」は日付区分の代表時計であり、追い切り意図や負荷、映像を新たに確認した意味ではない。遅い時計を一律に削除する変更もしていない。

また、当日以降・日付不明・存在しない暦日の時計を評価対象から除外。過去好走時比較に当日・未来の結果が混入しないようにした。

全240頭中54頭が変化。上昇49頭・低下5頭、変化幅は-5〜+8点。これは調教因子の部分比較で、TM INDEX全体の再生成・順位比較・回収率検証ではない。
