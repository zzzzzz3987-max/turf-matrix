# Blood 4〜5代血統カバレッジ監査 (2026-09-01)

## 結論

- JV-Linkの`BLDN/HN`繁殖馬マスタ161,774頭をローカル展開し、繁殖登録番号の親子IDから4〜5代を補完する処理を追加した。
- 現行`tools/week-data.json`の140頭すべてで、照合済み5代62祖先キャッシュを利用できる。
- キャッシュ適用後の4代取得済みは0頭から140頭、クロス検出馬は2頭から105頭へ増えた。
- 残り35頭は5代まで取得したうえで重複祖先が検出されなかった馬であり、未取得ではない。
- Blood Scoreの変更は0頭、最大絶対差0.000点。4〜5代とクロスは構造Evidenceにのみ使い、取得できたこと自体を加点しない。
- HNで不足した馬は0頭、本人照合拒否も0頭だった。JBISは今後も不足時だけ使う予備経路とする。

## 同期・照合方式

1. `JVOpen("BLDN", "19860101000000", 4)`でダイアログなしセットアップデータを開く。
2. `JVStatus`がダウンロード予定数へ達してから読み込みを始める。
3. HN以外の物理ファイルは`JVSkip`し、繁殖馬マスタだけをローカルJSONへ展開する。
4. 出走馬の取得済み3代血統にある繁殖登録番号から、父・母の親子IDを5代まで再帰的にたどる。
5. 既存キャッシュより深い場合だけ候補を作り、父・母・母父を中心とした本人照合を通す。
6. キャッシュ適用前後のBlood Scoreが異なる馬は保存を拒否する。
7. 1〜3代は引き続きJV-Linkを正本とし、HN/JBISは4〜5代を補完する。

## 役割分担

- JV-Link HN: 主経路。スタートキット不要。繁殖登録番号で決定的に親子をたどる。
- JBIS: HNで補えない例外馬の予備経路。完全一致とJV-Link本人照合を必須とする。
- レース別HTML: 保存済みなら最優先。HN/JBISキャッシュより深い、または同等の血統表をそのレースで利用できる。
