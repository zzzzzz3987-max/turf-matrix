## 1. 近走の「重み付け」が走数による減点になっている

`tools/intelligence/form-ai.mjs:72` で各走の点数に `1 - index * 0.08` を掛け、同89行以降では重み合計でなく走数で平均する。古い走りの比重を落とすと同時に、点数全体を下げる構造になっている。

同じ成績（中山芝1800m、16頭立て2着、0.2秒差、上がり34.0秒）を持つ入力で、1走85点、2走82点、3走78点、5走72点と再現した。これは実馬の結果比較ではなく、走数以外を固定した合成入力による計算特性の検査。

3走と5走の差6点は、特別レースの近走の実効比重20/95で約1.26点の指数差になり得る。別途、総合指数には3走未満を対象とする経験数補正もある。

古作特別はゴディアーモが近走75、デイジー64で、近走だけの首位側寄与差が+2.316。前者は過去3走、後者は17走（近走採点は最大5走）。西宮Sも近走の寄与差+2.737が最大だった。ただし実績内容も異なるため、この走数効果だけを不振の原因とは断定できない。

次の検証候補は重み合計で割る加重平均化。既存のスコア分布も変わるため、独立した修正候補として全保存日を比較し、未使用期間で確認する。

## 2. 斤量の個体耐性が実績を再加点している

`tools/intelligence/load-ai.mjs:158` は同等斤量で一定以上の成績を持つ馬へ+1を付与する。相対斤量が不利でない場合にも加算される。入力は着順・着差で、Ability・Form・Distanceにも既に使われる材料。

重複参照が確認できることと、それが統計的に過大評価であることは別。後者は今後の比較対象とする。

- 京成杯AH：ディールメーカーとエコロブルームは基本指数83同士。斤量補正+2対0で85対83になった。相対斤量項目は+1対-1、個体耐性は両馬+1。したがって、この2頭の差を作ったのは個体耐性の差ではなく相対斤量の差。
- 札幌2歳S：基本指数81対78から、デザートスピリット+1、コスモハナミズキ-1で最終82対77。5点差中2点は斤量による。ハナミズキは相対斤量-2を好走実績で1点軽減している。
- Fビレッジ特別と白井特別：斤量が首位側へ1点ずつ追加。

次の候補は「個体耐性を独立した好走ボーナスとする方式」と「相対斤量の不利を緩和する用途に限定する方式」の比較。今回だけを見て軽斤量評価を削る判断はしない。

## 3. Course点の同場・同形態実績が芝ダートを分離していない

`tools/intelligence/course-ai.mjs:42` のsameCourseと44行のsameTypeは、surfaceの一致を条件に含めていない。sameSurfaceを別項目で採点しても、同場ダートの好走が芝のsameCourseへ入ることは防げない。

今回中山芝、東京芝10着の1走だけを持つ合成入力はCourse54。同じ馬に中山ダート1着を3走追加すると82になった。実馬の能力向上ではなく、異なる馬場実績の混入を示す検査。

土曜は全体で17頭に該当。ただし指数1位・2位の18頭には同場の異馬場実績はなかったため、今回の首位不振の直接原因として扱わない。

次の修正候補はsameCourse・sameTypeを同じsurfaceへ限定すること。未経験条件の固定点も同時に点検するが、効果測定では変更を分離する。

## 4. 材料の欠損・未接続が残っている

調教未取得は中立60点で採点され、重みの分母に含まれる。実測で低評価だった60点と、未取得の60点は意味が異なる。上位2頭ではFビレッジ特別の両馬とコスモハナミズキが該当。

トラックバイアスは全113頭でmissing・補正0。当日の取得経路、更新対象、必要サンプル数のどこで欠けたかはこの採点監査では未解明。馬場状態（良・稍重等）の補正とは別である。

また、`tools/intelligence/index.mjs` の展開統合評価と `course-ai.mjs` の詳細コース形態は `scoreConnected: false`。詳細説明があることと、その情報が最終指数に入っていることを分けて管理する必要がある。

## 5. 寄与データには分母の違いがある

`tm-index-engine.mjs` の本体は重み合計（今回0.95）で割るが、既存 `buildIndexContributions` は割る前の `score * weight` を保存する。その単純合計を指数への実寄与と解釈すると一致しない。

今回追加した監査ツールでは保存された元スコアを同一バージョンの較正で処理し、分母・丸め・各補正・上限下限まで分解して点差を再現する。既存の指数本体に算術的不一致があるという意味ではない。
