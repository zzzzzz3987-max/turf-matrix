# TURF MATRIX 週末回顧｜20レース中14レースで指数上位3頭から勝ち馬

8月22日（土）・23日（日）に掲載した20レースを振り返ります。

今回は、各レースのTM INDEX 1〜3位をそれぞれ単勝・複勝100円ずつ購入した場合の成績を集計しました。数字はすべて公開時点の評価と、JV-Linkから取得した確定成績に基づいています。

## まずは結論

20レース中14レースで、TM INDEX上位3頭のいずれかが勝ちました。

指数上位3頭をすべて単勝で買った場合の回収率は135.0%。複勝回収率は74.3%でした。

今週は指数1位よりも、指数2位と3位が好成績でした。

・指数1位：3勝、単勝回収率97.0%

・指数2位：6勝、単勝回収率129.5%

・指数3位：5勝、単勝回収率178.5%

つまり、指数上位3頭全体ではプラスでしたが、利益の中心は指数2位と3位でした。

## 土曜の結果

土曜は10レース中7レースで、指数上位3頭から勝ち馬が出ました。

・単勝回収率：136.0%

・複勝回収率：71.3%

特に良かったのは指数2位です。10頭中4頭が勝ち、単勝回収率158.0%、複勝回収率116.0%でした。

主な的中馬は次の通りです。

・大府特別：指数1位 ライノ 1着（5番人気・単勝1,090円）

・長岡S：指数3位 ケーブパール 1着（4番人気・単勝1,270円）

・クローバー賞：指数2位 ブルージェイ 1着

・伊賀S：指数2位 ピエマンソン 1着

・オールスターJ第2戦：指数2位 キャントウェイト 1着

・ニセコ特別：指数2位 ロングミックス 1着

土曜はライノの単勝1,090円に加え、指数2位が安定して勝ち切った一日でした。

## 日曜の結果

日曜も10レース中7レースで、指数上位3頭から勝ち馬が出ました。

・単勝回収率：134.0%

・複勝回収率：77.3%

日曜は指数3位が10頭中4勝。単勝回収率230.0%を記録しました。

主な的中馬は次の通りです。

・キーンランドC：期待値タブ1位・指数3位 サウンドモリアーナ 1着（5番人気・単勝1,290円）

・新潟2歳S：指数3位 レッチュベルク 1着

・名古屋城S：指数3位 トリポリタニア 1着

・飯豊特別：指数3位 ホウオウシェリー 1着

・有松特別：指数2位 ビップディラン 1着

・豊川特別：指数1位 カーリキュー 1着

キーンランドCでは、期待値タブ1位・指数3位のサウンドモリアーナが1着、指数1位パンジャタワーが2着。指数と期待値の両面から上位2頭を捉えました。新潟2歳Sでも指数3位レッチュベルクが1着、指数2位トウシンマジックが2着でした。

## 指数1位だけを見るとどうだったか

指数1位は20頭中3勝、3着以内は9頭でした。

・勝率：15.0%

・複勝率：45.0%

・単勝回収率：97.0%

・複勝回収率：79.0%

約半数が3着以内に入りましたが、勝ち切れないレースも多く、単勝はわずかにマイナスでした。

このため今後は「指数1位だけ」ではなく、1位と2位の点差や、指数上位3頭の組み合わせまで確認する必要があります。

## 期待値表示の結果

実際に期待値タブへ表示された候補のうち、各レース上位3頭（条件により3頭未満のレースあり）は土日合計55頭でした。

・単勝回収率：43.3%

・複勝回収率：62.2%

日曜は、期待値タブ1位のサウンドモリアーナが5番人気で1着。マイネルフォルツァも11番人気で2着と、目立つ好走がありました。

ただし、表示された候補全体ではマイナスです。好走した穴馬だけを取り上げず、現段階では期待値を「強い推奨」ではなく参考情報として扱います。

## 今週の評価

良かった点は、指数上位3頭から20レース中14レースの勝ち馬を拾い、単勝回収率135.0%を記録したことです。

一方の課題は、指数1位の単勝回収率が97.0%にとどまったことと、期待値表示の回収率が不足したことです。

今後の回顧では、合算成績だけでなく、指数1位・2位・3位を必ず分けて掲載します。これにより、どの順位が結果を出したのかを明確にします。

また、相手候補は高いEVだけで選ばず、指数3〜5位の中から能力・近走・調教・展開の裏付けが強い馬を優先します。期待値候補は相手本線とは分けて検証を続けます。

TURF MATRIXは、的中した馬だけを取り上げるのではなく、公開した全評価を同じ条件で記録し、毎週改善していきます。
