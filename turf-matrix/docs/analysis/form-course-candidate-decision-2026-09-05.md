# 近走・コース修正候補の判断

## 今回の実装

- 近走: 過去走ごとの重みを合計した値で割る加重平均を、検証用オプションとして追加。同じ内容の走りを重ねるだけで評価が下がる現象を解消する。
- コース: 同じ競馬場・同じコース形態の実績を集める際、今回と同じ芝・ダートに限定する検証用オプションを追加。
- 本番の呼び出しと既定値は変更していない。公開指数、公開順位、自動オッズ更新にも変更なし。

## 判断と限界

コース修正は、芝の適性に同場のダート実績が混ざる問題を直接解消する。ただし、首位入替は1件だけで、勝数・複勝的中数・回収率の増加はない。8月30日札幌10Rはララバニュルス4着からルージュベルベット6着へ変更。精度向上や本番採用の根拠が揃ったとは扱わない。

近走の修正で計算上の走数依存は解消したが、得点水準も変わる。既存の能力評価との重複や総合指数の重みとの関係まで確認が必要。今回の成績低下は、元の計算を正しいとする理由にも、結果に合わせて係数を変更する理由にもしない。

近走修正での首位入替は8月30日新潟8R。ゾロアストロ1着からロデオドライブ2着へ変更した。候補では両馬85点で同点となり、馬番順でロデオドライブが首位となる。

9月5日の9レースは全候補で首位が変わらず、今回の土曜成績は改善しない。この日は問題発見に使ったデータなので、独立した検証データではない。残り10レースも探索的な過去比較であり、新規レースでの事前固定検証は0件。

他の因子と馬場・斤量等の補正は保存値に固定した部分比較。分析全体の再生成や新方式の運用実績ではない。除外レースがあるため、全掲載レースへ結果を一般化しない。
