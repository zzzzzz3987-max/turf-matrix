# 10/7 改善検証 第1段階

## 実装

公開ロール診断の結果アーカイブ読み込みに、JV-Linkの全レース確定結果形式を追加。
従来は `YYYY-MM-DD-results.json` のみを走査し、9/19以降に保存した
`YYYY-MM-DD-all-race-results.json` を診断に取り込めていなかった。
従来形式との互換性を維持し、同一開催日は重複集計しない。
日付不一致、未確定、払戻未取得、重複馬・レース、不正払戻はエラーで停止。
取消・除外と欠損着順を保持し、0着への変換はしない。
事前固定候補の評価側にも同じ読み込みを適用。

## 再検証

対象：7/25〜10/4の21開催日、特別レース161レース。
13:00 JST以前の保存予想に現行選出と既存caution-v1を適用した後方診断。
実際の各レース直前に公開された選出の成績ではない。
10/3・10/4回顧の公開実績とは母集団・時刻・ルールが異なり、合算しない。
事前固定による将来検証ではないため、改善効果の確証には使わない。

注目穴：現行106頭、3着以内率16.0%、複勝回収率70.0%。
既存候補12頭、3着以内率8.3%、複勝回収率22.5%。
危険な人気馬：現行81頭、3着外率63.0%、勝率12.3%。
既存候補25頭、3着外率60.0%、勝率8.0%。
候補は危険馬の勝率だけは下がるが、3着外率は改善しない。
対象を絞るだけでは改善と判断できず、両候補とも採用条件未達。

## 判断

公開の指数係数・軸・相手・危険判定は変更しない。
過去記事・公開選出を新ルールで書き換えない。
今週データの再生成、push、公開は行わない。

次段階では、能力面の不安とオッズ面の割高を別々に検証する。
軸と3連複相手については、発走前の買い目固定と的中券の確定払戻を
照合できる検証系を先に整える。変更案は時系列分割と将来の事前固定で比較する。
直近2日で有利だった閾値を選ぶことはしない。
