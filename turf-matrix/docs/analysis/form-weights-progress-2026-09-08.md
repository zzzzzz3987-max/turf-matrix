## 修正内容

現行は各走に 1.00 / 0.92 / 0.84 / 0.76 / 0.68 の重みを掛けた後、走数で割る。
5走なら重みの合計は4.20なので、同じ走りを重ねても1走だけの場合より点が下がる。
候補は重み付き合計を重み合計で割る。古い走りの重要度を下げる意図は維持する。

着順・着差・上がり・クラス・距離の各走評価は変更しない。
中央と地方の抽出、各区分直近5走、中央85%・地方15%、地方のみの中立点への補正も維持。
未経験50点、整数丸め、上限下限、総合指数への配分、経験走数補正も維持する。

## 保存と照合

発走前に入力・モデル・予測のSHA256と記録時刻を保存する。
